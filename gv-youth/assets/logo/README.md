# GV청소년선교회 로고 에셋

원본은 박재용 목사님이 구글 드라이브 `GV` 폴더에 넣어 둔 공식 로고입니다.
드라이브 파일 `GV청소년선교회.png`(757×185, 투명 PNG)를 그대로 받아 씁니다.
**로고를 다시 그리거나 글꼴·색을 새로 디자인하지 않습니다.** 아래 세 가지 가공만 했습니다.

| 파일 | 쓰는 곳 | 내용 |
| --- | --- | --- |
| `logo.png` | 헤더, 모바일 메뉴 상단 | 원본에서 아래쪽 영문 태그라인 띠만 지운 판본 |
| `logo-light.png` | 푸터, 어두운 패널 | `logo.png`의 워드마크(단색 #252525)만 흰색으로 바꾼 판본. 심볼의 파랑·초록·주황은 그대로 |
| `logo-original.png` | 보관용 | 드라이브 원본 그대로(손대지 않음) |
| `favicon-32.png` | 브라우저 탭 | 원본 왼쪽 심볼만 정사각으로 크롭 |
| `favicon-192.png` | 안드로이드 홈 화면 | 위와 같음(흰 배경) |
| `apple-touch-icon-180.png` | iOS 홈 화면 | 위와 같음(흰 배경) |

## 태그라인을 지운 이유

원본 PNG·AI 파일에는 워드마크 아래 `Great Vision Of Youth Mission` 영문 태그라인이
붙어 있는데, **오른쪽 끝이 아트보드에서 잘려 있습니다**(마지막 `Mission`의 `n`이 잘림).
헤더에 34~40px 높이로 줄이면 그 띠가 3px 남짓으로 뭉개져 잘린 글자가 얼룩처럼 보입니다.
그래서 태그라인 띠(원본 y 126 아래, 워드마크 오른쪽 영역)만 투명으로 지웠습니다.
워드마크 `회`의 오른쪽 세로획은 원본에서 완전한 획입니다(잘린 것이 아님).

## 크기 규칙

- 헤더: 높이 38px(≤860px 화면 32px, ≤560px 화면 30px), 가로는 비율대로 자동
- 모바일 메뉴 상단: 높이 34px
- 푸터: 높이 34px(≤560px 화면 32px)

## 다시 만들 때

```
python3 tools/make-logo-assets.py
```

`GV` 폴더의 `GV청소년선교회.png`, 파일 ID `1WTTgAqxzGE8LSGV7fQDj2uqYxyEDeT0F`).
