# 증명서 발급 앱 (`certificate/`)

대한예수교장로회(백석) 서울강동노회 증명서를 만들어 **인쇄 · PDF · 이미지(PNG)** 로 받는 설치형 웹앱(PWA)입니다.
주소: https://aichurchsystem.github.io/Church/certificate/

## 무엇을 할 수 있나
- 양식 관리(관리자) 탭: 지면의 모든 고정 글자를 앱에서 고치고 기본값으로 되돌리기
- 증명서 종류 여섯 가지: 재직증명서 · 소속증명서 · 교회 개척확인증명서 · 교회 설립증명서 · 노회 참석 확인서 · 노회비 납부증명서
- 이름을 고르면 `data/people.json` 의 명단에서 생년월일·주소·교회명·직위를 채웁니다.
- 발급일·증명서 번호(`노회(증) 제YY-NNNNN호`)·Internet No. 자동 생성(고칠 수 있음).
- 발신처(기본 서울강동노회)·수신처(그때그때 입력, 비우면 인쇄되지 않음).
- 발급 이력(종류·이름·수신처로 찾기, 월별 보기, CSV 내려받기, 눌러서 다시 출력).
- A4 한 장 인쇄, 홈 화면에 설치, 오프라인에서도 열림.

## 폴더
```
index.html            화면 + A4 지면
assets/app.css        화면·지면·인쇄 스타일 (지면은 mm 단위)
assets/app.js         동작 (정의를 읽어 폼과 지면을 그림)
data/types.json       증명서 종류별 정의 — 제목·항목·본문·추가 입력·워터마크
data/people.json      사람 명단 (교회명·이름·생년월일·주소·직위)
data/config.json      직인 기본 경로(seal) — 보통은 앱에서 직접 올리는 방식을 씁니다
assets/emblem.png     총회 엠블럼 워터마크(스캔에서 떠서 투명 PNG로 처리)
assets/band.png       보안 패턴 띠(스캔에서 추출)
vendor/html2canvas.min.js  이미지(PNG) 저장용
sw.js, manifest.webmanifest, assets/icons/  설치·오프라인용
```

## 고치는 법
- **문구·항목**: `data/types.json`. `body` 의 `{church} {name} {birth} {address} {position} {presbytery}` 는 입력값으로 바뀝니다. 앱 화면의 `본문 문구 수정` 에서도 종류별로 고칠 수 있습니다(그 기기 브라우저에만 저장).
- **명단**: `data/people.json` 의 `people` 배열에 사람을 더하면 됩니다.
- **양식 글자**: `양식 관리` 탭에서 지면 머리글·문서번호 접두어·하단 안내문·종류별 제목/본문/항목 이름/서명부 직함·성명을 고칩니다. 고친 값은 이 기기 브라우저에 저장되고 `기본값 복원` 으로 되돌립니다.
  - 지면 머리글 기본값은 세 줄입니다 — `대한예수교장로회(백석)  서울강동노회`(한 줄에 나란히) / 노회 주소 / `Tel: 02-429-1318  Fax: 02-429-1319`. 총회 주소는 기본값이 비어 있어 찍히지 않고, 양식 관리에서 채우면 그 줄이 다시 나옵니다.
- **직인**: `발급하기 → 서명부 직인` 에서 `서기 직인 / 노회장 직인 / 서울강동노회 직인 / 직인 없음` 중 고르고, 각 직인 이미지는 `넣기` 로 한 번씩 올려 둡니다. 이미지는 **그 기기 브라우저(localStorage)에만** 저장되고 이 저장소에는 올라가지 않습니다. 실제 인감이므로 저장소·공개 페이지에 두지 마세요.

## 주의
